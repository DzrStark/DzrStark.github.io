# Zirong Ding · 丁梓镕

Academic homepage for Zirong Ding. Open `index.html` directly or serve this directory with `python -m http.server 8000`. The site is static and uses relative asset paths. GitHub Pages can serve it from the root of the `main` branch.

## Editing

Edit the biography, experience, publications, awards and contact links in `index.html`. The layout and colors are in `style.css`. Replace `assets/zirong-ding.jpg` to update the sidebar portrait. The header and tab icon use the supplied DcStark logo. The brush font is subsetted to the four characters in 和光同尘.
